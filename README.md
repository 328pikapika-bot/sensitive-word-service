# 敏感词服务

[English](README.en.md) | 简体中文

基于 Flask 的文本检测 Web/API 服务，提供词库匹配、Plus 归一化匹配、文件文本抽取和模型语义审核。

## 主要功能

- 普通词库匹配配合词边界处理，Plus 增加部分字符归一化能力。
- 支持文本请求和 TXT/DOCX/PDF 内容抽取。
- 按需调用 OpenAI 兼容模型接口生成语义审核结果。

## 源码与运行入口

`源码/app.py` Flask 路由与文本处理；`源码/sensitive_plus.py` Plus 引擎；`源码/config.py` 配置；`源码/templates/` 页面。

Python 和 `源码/requirements.txt` 声明的依赖。进入 `源码/` 安装依赖、配置进程环境后执行 `python app.py`。默认端口 3309。

已从同项目归档补齐主程序、配置与 Plus 引擎。默认使用 `源码/sensitive_words.example.txt` 两条合成词，仅验证结构；实际使用需提供自己的 UTF-8 词库。

## 配置

词库路径使用 `SENSITIVE_WORDS_PATH`；模型配置使用 `LLM_API_KEY`、`LLM_API_URL`、`LLM_MODEL_NAME`。本项目读取进程环境，不会自动加载 `.env`。

配置示例位于源码中的 `.env.example`。真实凭证只保存在本机环境或不跟踪的 `.env` 中。`127.0.0.1` 与 `example.invalid` 为本地/不可解析示例地址，部署前替换为自己的配置。

## 验证与边界

完整业务词库不公开。词库匹配与模型意见都不能代替人工判断；对外部署须核对鉴权、服务端路径读取、上传和 URL 访问限制。本次未启动 HTTP 服务或调用模型。
